# 🛡️ SIEM Log Analysis

A hands-on cybersecurity learning repository focused on **SIEM fundamentals, security log analysis, alert triage, and SOC Analyst L1 investigation methodology**.

## 🎯 Objectives

* Understand the role of a SIEM in security monitoring
* Learn how security events are analyzed
* Practice alert triage
* Identify potentially suspicious activity
* Understand severity and prioritization
* Document investigation findings
* Develop SOC Analyst L1 investigation skills

## 🔎 Core Areas

### 📊 Security Log Analysis

* Authentication events
* Network activity
* Process activity
* Security events
* Event timelines

### 🚨 Alert Triage

* Alert validation
* Severity assessment
* False-positive identification
* Evidence collection
* Analyst notes

### 🔍 Investigation

* Event correlation
* Indicators of compromise (IOC) concepts
* User and host context
* Timeline development
* Escalation decisions

## 🧠 SOC Investigation Methodology

```text
Alert
  ↓
Validate
  ↓
Identify Affected User / Host
  ↓
Collect Relevant Logs
  ↓
Correlate Events
  ↓
Assess Severity
  ↓
Document Findings
  ↓
Escalate if Required
```
